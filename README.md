# Dad Joke Showdown

**Winning entry:** "I told my son to embrace his mistakes. He gave me a hug."

A single dad joke (56 characters) written to be told out loud.

## Run

```
python3 main.py
```

The program writes the joke to `/output/entry.txt` (creating the directory if needed) and prints it to stdout.
